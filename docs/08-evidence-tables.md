### 仮説1 — 多社並行・活動量（管理単位の多さ）

- **仮説**: 並行応募により企業×選考の情報・準備負荷が乗る。
- **調査結果（キャリタス・本線）**: 2026卒モニター（2025/5/1時点）でエントリー平均 **23.4社**、ES **10.8社**、面接 **6.7社**。[FACT]
- **旧02との数値差**: 旧表のエントリー25.3／面接7.7は更新前。本稿・03は確報 **23.4／6.7** を正とする。[FACT]
- **参考（別ソース）**: マイナビ系モニターでは累計エントリーがより高い数字が出る場合あり（旧02: 28.5社・6月末累計）。定義・時点が違うため **本線に混ぜない**。[FACT]（旧02記載）／[INFERENCE]（非統合）
- **偏り・注意**: キャリタスモニター。全国全就活生の厳密な母集団推定ではない。
- **示唆**: 「1人あたりの管理・準備単位が多い」方向の公開支持。深い管理が必要なのは選考が進んだ数社、という旧02示唆は **入口設計**に残す（管理アプリ完結にはしない）。[INFERENCE]

## ③ 市場規模モデル（基準推計）

**定義の先置き**: ここでの市場は「就活ナビの広告TAM」でも「紹介料TAM」でもない。06枠の **個人の選考経験を次準備に活かすための道具／習慣** に関わる **潜在ユーザー人数** の基準推計（円建て単価は未ロックのため人数のみ）。[INFERENCE]

### 定義

| 層 | 定義 | 基準年 |
| -- | ---- | ------ |
| **TAM** | 日本の大学生・大学院生のうち、当該卒業年次に **民間企業への就職を希望する者**（Works「民間企業就職希望者数」） | **2026卒**（調査公表2025年4月） |
| **SAM** | TAMのうち、**多数企業への並行応募により、選考準備・情報整理の負荷が乗る層**（06 Inの入口＋コアが意味を持ちうる人数レンジ）。学校推薦・1〜2社のみは初期外（06 Out） | 同左＋活動量は2025/5モニターで sanity |
