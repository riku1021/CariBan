# Competitive Position (代替比較・市場座標)

> **状態: LOCKED** — 2026-08-20 ユーザー決裁（09 LOCK）。代替に対する立ち位置の基準表。

## 🎯 このドキュメントの結論

> **勝つ一文**: 並行選考で毎回ゼロから準備したくない就活生に対し、無料トラッカー＋Notion／Calendar＋ナビの組み合わせが解けない「選考学びと『企業×自分』文脈の次への引き渡し」で選ばれる。[HYPOTHESIS]
>
> **最強代替**: **無料の選考トラッカー＋汎用メモ（Notion／Calendar）＋ナビサイト** — 管理と締切はここで足り、学び連鎖まで払う必要がないと感じる。[HYPOTHESIS]（03 引用）
>
> **やらない戦い**: OpenWork型の企業口コミ網羅、マッチング本業、紹介料モデル、面接音声の第三者共有、**管理だけの Todo／企業リスト完結**。[FACT]（06 Out）

> 本稿は **代替に対する立ち位置の基準表（canonical 候補）** である。Problem・In/Out・TAM・WTP・機能MRDは再発明しない。カテゴリ名は07に依存せず後置・任意。consideration set の実態は **11** で確認する。

### 2軸マップ（意味のある独立軸があるため採用）

軸は「高機能↔低機能」「高価格↔低価格」ではない。

- **横軸**: 企業情報の資産化 ←→ **個人履歴の資産化**
- **縦軸**: 記録が浅い／単発 ←→ **記録が深く横断一貫**

```text
  深い・横断一貫
        │
        │         ★ 本アイデア（仮説）
        │              （個人履歴 × 深い引き渡し）
        │    Naitei Path（個人・ラウンド記録）
        │
────────┼────────────────────────────
 企業情報│  OpenWork／就活会議     無料スタック
 資産化  │  （企業情報×深さは口コミ） （個人だが深さは手作業）
        │
        │         管理リマインダー
        │         何もしない
  浅い・単発
```

| 象限・空白の読み | 扱い |
| ---------------- | ---- |
| 右上（個人×深い）に近い空白 | **自動で機会確定しない**。無料スタックで「足りる」なら空白は顧客に認識されない（K1・11） |
| 左（企業情報） | **やらない戦い**。ここに寄ると06 Out侵食 |
| 下（浅い管理） | 参入容易・差別化弱い（03）。コアにしない |

カテゴリ名は後置・任意（例: 「個人の選考経験資産化」）。OS／Platform 格上げはしない。07のコピー確定を待たない。
