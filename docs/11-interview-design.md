## 🎯 このドキュメントの結論

> **壊す仮説Top3**: ① **PS3**（面接・選考の学びが次に渡らず、毎回ゼロから準備する）が **Top 3 Pain** か ② **管理だけで十分**（K1）か ③ **非共有のメモ/録音** でコア Job が回るか（C2）。**15–20名**・**過去行動中心**・**ソリューション説明は最後15分以内または無し**。件数の多数決で判定しない。[HYPOTHESIS]

## ② 募集

### 主サンプル（15–18名）

| セグメント | 条件（暫定ICP） | 人数 | 入手方法（Watering hole） |
| ---------- | --------------- | ---- | ------------------------- |
| **A. 自己管理型** | 10社+エントリー、Notion/Sheet/メモで管理中、面接3回+ | 5–6名 | 大学キャリアセンター紹介、就活X/LINEオープンチャット、創業者ネットワーク |
| **B. エージェント1社** | 10社+、エージェント1社、3社+選考並行 | 5–6名 | 新卒紹介エージェント経由（マイナビ新卒紹介等）、知人紹介 |
| **C. エージェント2社+** | 10社+、エージェント2社+、日程提示の手間を自覚 | 5–6名 | 同上＋創業者と同型の就活生 |

**共通必須**: 民間就活中（27/28卒可）。**除外（10非ターゲット）**: 1–2社のみ、学校推薦内定済み、就活ツールを一切使わず問題なし層。

### Contrast Interview（別枠・2名）

| 条件 | 目的 |
| ---- | ---- |
| エントリー5–8社、面接1–2回 | H1が **高活動層特有** か見る。主サンプルと **合算しない** |

### スクリーニング（募集前）

- 現在のエントリー社数 / 選考並行数 / 面接回数
- 使用中ツール（ナビ・エージェント・Notion等）
- **有償インタビューはしない**（ギフトカード500円程度は可）

## ④ 禁止・注意

| 禁止 | 理由 |
| ---- | ---- |
| 「使いたいですか」「便利そうですね」 | 安価な肯定 |
| 前半で就活OSの機能説明・AI宣伝 | Problem を壊せない |
| 仮説朗読→「そうですよね？」 | 反証不能 |
| 27問一括アンケート化 | 深掘り不能 |
| 「20人中8人」多数決だけで H1 支持 | 04/11 判定原則違反 |
| Contrast 2名を含めて「18人中12人」 | セグメント混ぜ禁止 |
| 録音の **共有・投稿** を前提に聞く | 03 K2・就活OS非共有設計と不一致 |

**インタビュアー**: 創業者本人可。**同世代バイアス** に注意。可能なら **1/3は第三者** が聞き手。

## ⑥ 判定・更新ルール

### 原則

- **多数決禁止**。Pain Top3 の **反復パターン** + **具体場面の有無** + **行動強度**（時間・習慣）で見る
- **明確な反証1件**（例：ICP内でPS3が半年0回）でも H1 を軽く扱わない
- **停止条件**: 連続5名で H1 に関する **新パターンが出ない**、または H1/H2 が **明確に壊れた** → 追加募集を止め 06/10 を更新
- **停止 ≠ 支持**

### シグナル表

| ID | 支持方向（≠証明） | 反証方向 | 更新先 |
| -- | ----------------- | -------- | ------ |
| H1 | 直近3ヶ月に忘却/ゼロ準備の **具体場面** が複数回。Pain **Top3** | ほぼなし／Top3外。我慢で済む | **06**, 10 |
| H2 | 管理Pain Top1。記録習慣なしでも問題なし | 管理だけでは足りないと **自発** 訴求 | 06 |
| H3 | 非共有メモ/録音 **可**。メモだけでも価値 | 全面拒否。共有前提のみ | 17, 12 |
| H4 | 既存ツールに **時間投資** 済みだが横断/一貫性に **不満** | 完全満足 | **09** |
| H5 | 募集の **70%+** が暫定ICP一致 | 条件合致が少数 | **10** |
| H6 | 二重提示 **具体エピソード** | 経験なし多数 | 12（入口優先度） |

### 04条件との対応

| 04条件 | 11で見るID | 次に進む目安（設計時点・非機械） |
| ------ | ---------- | -------------------------------- |
| C1 | H1 | ICP内で PS3 関連Painが **反復**し、管理単独Top1だけではない |
| C2 | H3 | 非共有メモ/録音に **拒否以外** の選択肢が複数 |
| C3 | H2 | → **14**（プロトタイプ継続比較。11だけでは不足） |
